Data Analysis Projects

## Project 1: Titanic Dataset Analysis
- **File**: 'titan_train.csv'
- **Description**:Exploratory Data Analysis of the Titanic dataset
- **Skills used**: Python, Pandas, Seaborn and Matplotlib, Data Visualization, CSV handling

### Visualization included:
1. Age Distribution by Passenger Class - 'age_by_class.png'
2. Survival Count by Sex - 'survival_by_sex.png'
3. Correlation Heatmap - 'correlation_heatmap.png'

## How to run
1. Download 'titan_train.csv'
2. Run 'titanic_seaborn_analysis.py' to generate the plots
